Approach 1: Chatbot Assistance

What are AI Chatbots?

Conversational interfaces that:

  • Understand natural language questions
  • Generate code based on descriptions
  • Explain existing code
  • Debug and suggest improvements
  • Iterate based on your feedback

Examples: ChatGPT, Claude, duck.ai, Perplexity

duck.ai Overview

Features

  • Free and privacy-focused
  • Multiple AI models
  • Code-aware responses
  • No account required
  • Built by DuckDuckGo

Best for

  • Quick code generation
  • Learning new functions
  • Understanding errors
  • Exploring approaches
  • Documentation assistance

Tips for Effective Chatbot Prompts

  1. Be specific - “Create a ggplot2 bar chart” vs “Make a chart”
  2. Provide context - Share data structure, column names, goal
  3. Iterate - Start simple, then refine
  4. Review carefully - AI can make mistakes
  5. Ask for explanations - Understand the code, don’t just copy

Approach 2: GitHub Copilot

What is GitHub Copilot?

An AI pair programmer that:

  • Suggests code as you type
  • Completes entire functions
  • Adapts to your coding style
  • Works within your IDE
  • Learns from context in your files

Availability: Free for students, paid for others

How Copilot Works

You write:

# Calculate mean water quality
# by district and year

Copilot suggests:

# Calculate mean water quality
# by district and year
water_summary <- water_data |>
  group_by(district, year) |>
  summarise(
    mean_quality = mean(quality,
                       na.rm = TRUE)
  )

When to Use Copilot

✅ Good for:

  • Writing repetitive code patterns
  • Boilerplate function structures
  • Common data transformations
  • Test case generation

⚠️ Be cautious:

  • Always review suggestions
  • May suggest outdated approaches
  • Not always idiomatic R
  • Security implications with sensitive data

Copilot in RStudio

Setting up Copilot in RStudio

  1. Install the Copilot extension (Tools → Global Options → Copilot)
  2. Sign in with your GitHub account
  3. Start typing - suggestions appear as grey text
  4. Press Tab to accept, Esc to reject

Learn more: docs.github.com/copilot

Approach 3: Agentic Work Mode

What are Agentic AI Tools?

AI assistants that can:

  • Execute complex multi-step tasks
  • Read and write files autonomously
  • Run code and review results
  • Debug and iterate automatically
  • Manage entire workflows

Example: Claude Code (formerly Cascade)

Claude Code Overview

Capabilities

  • File system access
  • Code execution
  • Git operations
  • Multi-file editing
  • Autonomous debugging
  • Context-aware decisions

Use Cases

  • Refactoring projects
  • Building new features
  • Debugging complex issues
  • Setting up workflows
  • Analyzing codebases

Approach 4: R Packages for AI

AI-Powered R Packages

Programmatic access to AI capabilities:

ellmer

  • New package from Posit
  • Interface to multiple LLMs
  • Structured data extraction
  • Function calling support
  • Cost-effective for batch tasks

Others to explore

  • gptstudio (RStudio addins)
  • tidychatmodels (tidy interface)
  • openai (direct API access)
  • anthropic (Claude API)

Why Use R Packages?

  1. Reproducibility - Code-based workflows you can rerun
  2. Automation - Process many files/tasks programmatically
  3. Integration - Seamless with existing R pipelines
  4. Control - Fine-tune model parameters and prompts
  5. Cost tracking - Monitor and optimize API usage

ellmer: Data Extraction Example

library(ellmer)
library(pdftools)

# Read PDF content
pdf_text <- pdftools::pdf_text(
  "3-2351-7-1448552001.pdf"
) |>
  paste(collapse = "\n")

# Create chat with extraction prompt
chat <- chat_claude() |>
  chat_append("Extract data availability from this SFD report...")

# Get structured response
result <- chat_perform(chat, data = pdf_text)

# Process into dataframe
extract_data_frame(result)

API Costs Overview

Using AI programmatically has costs. Here’s what to expect:

Model Input (per 1M tokens) Output (per 1M tokens) Typical PDF
Claude Haiku $0.25 $1.25 ~$0.01
Claude Sonnet $3.00 $15.00 ~$0.15
GPT-4o mini $0.15 $0.60 ~$0.01
GPT-4o $2.50 $10.00 ~$0.12

Cost Management

  • Start with cheaper models (Haiku, mini)
  • Process in batches
  • Cache common queries
  • Monitor usage with API dashboards

Setting Up API Access

Claude (Anthropic)

  1. Go to console.anthropic.com
  2. Create account
  3. Add payment method
  4. Generate API key
  5. Set ANTHROPIC_API_KEY in .Renviron

GPT (OpenAI)

  1. Go to platform.openai.com
  2. Create account
  3. Add payment method
  4. Generate API key
  5. Set OPENAI_API_KEY in .Renviron

Security: Never commit API keys to Git! Use .Renviron or password manager.

Best Practices for AI-Assisted Coding

  1. Always review - Don’t blindly trust AI output
  2. Understand the code - Ask for explanations
  3. Start simple - Iterate towards complexity
  4. Version control - Commit before major AI changes
  5. Test thoroughly - AI can introduce subtle bugs
  6. Learn continuously - Use AI as a teaching tool
  7. Respect privacy - Be careful with sensitive data

When to Use Which Approach?

Approach Best For Time Investment
Chatbot Learning, quick tasks, brainstorming Low
Copilot Writing code, repetitive patterns Medium
Agentic Complex refactoring, large projects High
R Packages Batch processing, automation, APIs Medium-High

Pro tip: Combine approaches! Use chatbots to learn, Copilot while coding, packages for production.

Ethical Considerations

  • Attribution - Understand licensing of AI-generated code
  • Privacy - Don’t share confidential data with AI services
  • Dependency - Balance AI assistance with skill development
  • Bias - AI models can reflect biases in training data
  • Verification - You’re responsible for code quality and correctness
